# reset

The `reset` method restores the store to its initial state.

## How to Reset the Store

Call `store.reset()` to revert all state values to what you defined in `createStore`. This will also trigger a re-render in any components that are subscribed to the changes.

```ts
store.reset();
```

## Example

```tsx
function Settings() {
  const { settings, dispatch, reset } = store;

  const handleReset = () => {
    reset();
  };

  return (
    <div>
      {/* ... */}
      <button onClick={handleReset}>Reset to Defaults</button>
    </div>
  );
}
```

```tsx
import { createStore } from 'finalstore';

const store = createStore({
  states: {
    count: 0,
    user: null as { name: string } | null
  },
  actions: {
    increment: (state) => {
      state.count++;
    },
    setUser: (state, user: { name: string }) => {
      state.user = user;
    }
  }
});
```

## Basic Usage

```tsx
function ResetButton() {
  return (
    <button
      onClick={() => {
        store.reset();
        console.log('Store reset to:', store.get());
      }}
    >
      Reset Store
    </button>
  );
}
```

## With Cleanup

```tsx
function CleanupExample() {
  React.useEffect(() => {
    // Cleanup on unmount
    return () => {
      store.reset();
    };
  }, []);

  return <div>Component with cleanup</div>;
}
```
