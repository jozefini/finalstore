# Reset states

Every store you create comes with a built-in `reset()` method.

Calling `store.reset()` reverts all state values back to the `initialStates` you provided when creating the store. This is useful for clearing user data on logout, resetting a form, or anytime you need to return to a clean slate.

## Basic Usage

It's a simple, zero-argument function call.

```ts
// This will revert all states in the store to their initial values.
store.reset();
```

## Example in a Component

You can destructure `reset` directly from the store instance for clean use in your components.

```tsx
function SettingsManager() {
  const { reset } = store;

  const handleResetClick = () => {
    reset();
  };

  return (
    <button onClick={handleResetClick}>Reset All Settings to Default</button>
  );
}
```
