# Use Reactive States

The `use()` hook provides **reactive**, synchronous access to your store's state from within React components.

Use this hook to bind your components to the store. Any component that calls `use()` will automatically re-render whenever the specific piece of state it subscribes to changes.

First, let's set up a store to use in our examples:

```ts
// store.ts
import { createStore } from 'finalstore';

// 1. Create store types
type States = { ... }
type Actions = { ... }
type Selectors = {
  userAge: () => number;
  getTodoById: () => Todo;
};

// 2. Pass types to createStore.
const store = createStore({
  states: {
    user: { name: 'John Doe', age: 30 },
    todos: [{ id: 1, text: 'Learn finalstore', completed: true }]
  },
  selectors: ({ states }) => ({
    userAge: () => states.user.age,
    getTodoById: (id: number) => {
      return states.todos.find((todo) => todo.id === id);
    }
  })
});
```

## Subscribing to the Entire State

Call `use()` with no arguments to subscribe your component to the _entire_ state object.

**Note:** Use this with caution. It will cause the component to re-render whenever _any_ value in the state changes.

```tsx
function ProfileHeader() {
  const state = store.use();
  return <h1>{state.user.name}'s Profile</h1>;
}
```

## Subscribing to Specific State (Inline Selector)

Pass a selector function to `use()` to subscribe to a specific slice of state. This is the recommended approach for performance, as the component will only re-render when the selected value changes.

```tsx
// Subscribes to a single value
function UserAge() {
  const age = store.use((state) => state.user.age);
  return <p>Age: {age}</p>;
}

// Subscribes to a nested object
function UserInfo() {
  const { name, age } = store.use((state) => state.user);
  return (
    <p>
      {name} is {age} years old.
    </p>
  );
}
```

## Subscribing with Pre-defined Selectors

Access your [pre-defined selectors](./selector#pre-defined-selectors) directly on the `use` object. This is the cleanest way to reuse state logic across multiple components.

```tsx
// Using a simple pre-defined selector
function AgeDisplay() {
  const age = store.use.userAge();
  return <p>User's age is {age}</p>;
}

// Using a selector that accepts an argument
function TodoItem({ id }: { id: number }) {
  const todo = store.use.getTodoById(id);
  return <li>{todo.text}</li>;
}
```
