# Dispatch

The `dispatch` object is how you execute actions to update your store's state.

Every function you define in the `actions` object of your store is made available on `store.dispatch`.

First, let's set up a store with some actions to use in our examples:

```ts
// store.ts
import { createStore } from 'finalstore';

// 1. Define your types
type States = {
  count: number;
  isLoading: boolean;
};

type Actions = {
  increment: () => void;
  incrementBy: (amount: number) => void;
  fetchCount: () => Promise<number>;
};

// 2. Pass types to createStore
const store = createStore<States, Actions>({
  states: {
    count: 0,
    isLoading: false
  },
  actions: ({ states, notify }) => ({
    increment: () => {
      states.count++;
    },
    incrementBy: (amount: number) => {
      states.count += amount;
    },
    async fetchCount() {
      states.isLoading = true;
      notify(); // Immediately updates UI to show loading state

      try {
        const response = await new Promise<number>((resolve) =>
          setTimeout(() => resolve(Math.floor(Math.random() * 100)), 500)
        );
        states.count = response;
        return response;
      } finally {
        states.isLoading = false;
        // Final notification happens automatically
      }
    }
  })
});
```

## Dispatching Actions

Call actions via the `dispatch` object. If your action takes arguments, pass them directly.

```ts
// Dispatch an action without arguments
store.dispatch.increment();

// Dispatch an action with an argument
store.dispatch.incrementBy(10);
```

## Dispatching in React

In your components, it's common to destructure actions from `store.dispatch` and call them in event handlers.

```tsx
function Counter() {
  const count = store.use((state) => state.count);
  const { increment, incrementBy } = store.dispatch;

  return (
    <div>
      <h1>{count}</h1>
      <button onClick={increment}>+1</button>
      <button onClick={() => incrementBy(5)}>+5</button>
    </div>
  );
}
```

## Batching Dispatches

To optimize performance, you can group multiple synchronous state updates into a single re-render using `store.batch()`.

Any `dispatch` calls made inside the `batch` callback will update the state, but components will only be notified to re-render **once**, after the entire batch has completed.

```ts
function handleComplexUpdate() {
  store.batch(() => {
    store.dispatch.increment(); // State changes
    store.dispatch.incrementBy(10); // State changes again
    // ... any number of synchronous dispatches
  });
  // React components re-render only ONCE here.
}
```

**Note:** Batching is intended for synchronous actions. Asynchronous actions inside a `batch` will still trigger their own notifications as they complete.

## Dispatching Async Actions

When you dispatch an async action, it returns a `Promise` that resolves with the action's return value when it completes.

```ts
async function handleFetch() {
  console.log('Fetching new count...');
  const newCount = await store.dispatch.fetchCount();
  console.log(`New count is: ${newCount}`);
}
```
