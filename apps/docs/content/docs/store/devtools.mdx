# DevTools Integration

`finalstore` comes with built-in support for the Redux DevTools Extension, allowing you to inspect state, track actions, and time-travel debug your application with ease.

## Enabling DevTools

To connect your store to the DevTools, simply add a `config` object when you create it and set `devtools` to `true`.

It's highly recommended to only enable this in development to avoid any performance overhead in production.

```ts
// store.ts
import { createStore } from 'finalstore';

const store = createStore({
  states: {
    // ... your states
  },
  actions: {
    // ... your actions
  },
  config: {
    name: 'MyAppStore', // This name will appear in the DevTools instance list
    devtools: process.env.NODE_ENV === 'development'
  }
});
```

That's it! Once your application is running, open the Redux DevTools extension in your browser to start debugging.

## Features at Your Fingertips

Connecting to the DevTools unlocks a powerful set of debugging capabilities:

- **Action History:** See a real-time log of every action dispatched, along with its payload.
- **State Inspection:** View a snapshot of your entire state tree after each action.
- **Time-Travel Debugging:** Jump back and forth between states to understand how your application's state has changed over time.
- **Action Replay:** Replay a sequence of actions to reproduce a specific state or bug.

These features make it significantly easier to trace bugs and understand the flow of data in your application.
